Relations and Functions

Functions: one-one, onto and inverse

A function assigns each input exactly one output. Two questions decide how well-behaved it is: does every output come from only one input (one-one), and does every possible output actually get used (onto)? If both hold, the function can be run backwards, and the graph of the inverse is the mirror image of the original in the line y = x.

  • A relation from A to B is any subset of A × B. It can be reflexive, symmetric, transitive; all three together make an equivalence relation.
  • One-one (injective): f(x₁) = f(x₂) implies x₁ = x₂. On a graph, every horizontal line meets the curve at most once.
  • Onto (surjective): range = codomain. Changing the codomain can change whether a function is onto.
  • Bijective means one-one and onto. Only bijections have an inverse f⁻¹, and (f⁻¹ ∘ f)(x) = x.
  • Restricting the domain, for example x² on x ≥ 0, can make a function one-one so that it gains an inverse.

In the real world

Converting temperature is a bijection R → R: F = 9C/5 + 32. Its inverse is C = 5(F − 32)/9. A forecast of 45 °C in Nagpur is 9×45/5 + 32 = 81 + 32 = 113 °F; going back, 5(113 − 32)/9 = 5×81/9 = 45 °C. Because the function is one-one, no two Celsius values share a Fahrenheit value, so the conversion can always be undone.

Counting: a one-one function from A = {1, 2, 3} to B with 5 elements can be built in 5×4×3 = 60 ways (each element needs a new image). The number of onto functions from a 4-element set to a 3-element set is 3⁴ − 3×2⁴ + 3 = 81 − 48 + 3 = 36.

Which statement about f: R → R, f(x) = x², is correct?

f(2) = f(−2) = 4, so it is not one-one. Negative numbers are never outputs, so the range [0, ∞) is smaller than R, and it is not onto. Restricting to [0, ∞) → [0, ∞) makes it bijective.
