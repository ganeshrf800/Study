Determinants and Matrices

Determinants, inverse and solving linear equations

The determinant of a square matrix is a single number that says how much the matrix scales area (2 × 2) or volume (3 × 3), and whether it flips orientation. If that number is not zero the matrix can be undone: the inverse A⁻¹ exists, and a system AX = B has the unique solution X = A⁻¹B, which is the same answer that Cramer's rule gives with determinants.

  • |A| = 0 means the matrix squashes the plane or space onto a lower dimension: it is singular and has no inverse. |A| ≠ 0 means non-singular.
  • Expanding along any row or column gives the same value; a row of zeros, or two equal or proportional rows, makes |A| = 0. Swapping two rows changes the sign.
  • Minor Mij is the determinant left after deleting row i and column j; cofactor Cij = (−1)i+jMij; adj A is the transpose of the cofactor matrix.
  • For AX = B with |A| ≠ 0 there is exactly one solution. If |A| = 0 and (adj A)B ≠ 0 the system is inconsistent; if |A| = 0 and (adj A)B = O it has either infinitely many solutions or none.
  • The area of a triangle with vertices (x₁, y₁), (x₂, y₂), (x₃, y₃) is ½ times the absolute value of a 3 × 3 determinant; three points are collinear exactly when it is 0.

In the real world

A CT scanner sends X-ray beams through the body along different paths and measures how much each beam is weakened. For a toy slice with three cells of unknown attenuation x, y, z, three beams give: x + y + z = 6, x + 2y + z = 8 and x + y + 3z = 12 (the coefficients are path lengths through each cell). Here |A| = 1(6 − 1) − 1(3 − 1) + 1(1 − 2) = 2. Replacing a column by the constants gives D₁ = 2, D₂ = 4, D₃ = 6, so x = 1, y = 2, z = 3. Check beam 3: 1 + 2 + 9 = 12.

Real scanners solve millions of such equations at once, and when two beams repeat the same path (|A| = 0) the data cannot fix the cells uniquely, which is why scanners use many angles. For the 2 × 2 matrix [2 3; 1 4] in the first widget, |A| = 8 − 3 = 5 and A⁻¹ = ⅕ [4 −3; −1 2].

A is a 3 × 3 matrix with |A| = 4. What is |adj A|?

For an n × n matrix |adj A| = |A|n−1. With n = 3 that is 4² = 16. (By contrast |2A| = 2³ × 4 = 32.)
