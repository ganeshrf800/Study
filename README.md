# Study

Interactive study lessons, published with GitHub Pages.

- `STD12/` Class 12 CBSE/NCERT textbook: Physics, Chemistry, Mathematics and Biology. Open `STD12/index.html`.
- `Mobile/` Interactive flagship phone block diagram with 10 module pages. Open `Mobile/index.html`.
- `Mobile/` Interactive block diagram of a 2026 flagship mobile phone with 10 module pages (SoC, modem, RF transceiver, RF front-end, antennas, GNSS, mmWave, Wi-Fi/BT, NFC/UWB, power), 8 component pages (LNA, PA, mixers, synthesizers, ADC/DAC, SAW/BAW filters, switches, DPD/ET) and five interactive studies (intermodulation, RF gain budget and dynamic range, modulation schemes, power consumption, thermal). Open `Mobile/index.html`.

The site is plain static files with no build step.
