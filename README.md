# Study

Interactive study lessons, published with GitHub Pages.

- `STD12/` Class 12 CBSE/NCERT textbook: Physics, Chemistry, Mathematics and Biology. Open `STD12/index.html`.
- `Mobile/` Interactive flagship phone block diagram with 10 module pages. Open `Mobile/index.html`.
- `Mobile/` Interactive block diagram of a 2026 flagship mobile phone with 10 module pages (SoC, modem, RF transceiver, RF front-end, antennas, GNSS, mmWave, Wi-Fi/BT, NFC/UWB, power), 8 component pages (LNA, PA, mixers, synthesizers, ADC/DAC, SAW/BAW filters, switches, DPD/ET) and five interactive studies (intermodulation, RF gain budget and dynamic range, modulation schemes, power consumption, thermal), and seven software pages covering the stack from apps to firmware (stack map, boot & security, modem, RF control, connectivity, multimedia & AI, power & thermal). Open `Mobile/index.html`.
- `MobileComms101/` Mobile Communications 101: a first course covering communication basics, wireless propagation and link budget, modulation, MIMO and carrier aggregation, mobile standards 1G to 5G, transmitter and receiver chains, architectures, gain budget analysis, performance metrics, 3GPP specifications, test cases and test procedure, organised in tabs as an engineering reference (propagation models, MAPL budget, BER, MCS/TBS, MIMO receivers and CSI, NR frame and procedures, UE power control, impairments, EVM and desense budgets, requirement derivation, uncertainty, OTA and production test) with interactive labs (Shannon capacity, link budget, bits-to-waveform, constellation/EVM, spectrum per modulation scheme, OFDM subcarriers, NR carrier calculator, receiver cascade) and a quiz. Open `MobileComms101/index.html`.
- `Laptop/` Interactive block diagram of a 2026 premium laptop (Panther Lake-class SoC, LPDDR5X, NVMe, dGPU, Thunderbolt 4, USB-C power path, EC) with costs, protocol view, signal-path presets, interface speeds, PCIe lane map, ports, firmware & software layers and a battery-life study. Open `Laptop/index.html`.
- `Memory/` Computer Memory: interactive technical reference. Fundamentals (hierarchy, DRAM internals, DDR, lanes, 2×16 / 4×16, phone vs PC) plus a sourced industry reference (technology map, standards status, modules, timings, ECC, HBM/CXL, market, A–Z glossary). Open `Memory/index.html`.
- `PCIe/` Interactive guide to PCI Express: topology, lanes, generations 1.0 to 8.0, form factors, PCIe in phones, and NVMe card testing with LTSSM loopback, a simulated BER bench and Linux commands. Open `PCIe/index.html`. `PCIe/evolution.html` is an interactive lesson on how the protocol changed from 1.0 to 8.0 (signalling, encoding, equalization, packets, reliability) with a quiz.
- `Satellite/` Design and analysis of PhoneSat-LTE, a 12U CubeSat that photographs Earth and sends the picture directly to an unmodified LTE phone: requirements, architecture trade, budgets, drawings, test plan, licensing and schedule. Open `Satellite/index.html`.

The site is plain static files with no build step.
