01 · Memory basics

Why computers have a memory hierarchy

A processor can do billions of operations per second, but storage that is both huge and fast doesn't exist. So systems stack several kinds of memory: tiny and very fast near the CPU core, big and slow farther away. DRAM (“main memory” or RAM) sits in the middle — this guide is about that layer.

Think of it like your brain 🧠

You already use a memory hierarchy every day. Imagine doing math homework: what is 7 × 8 + 15? Tap a row (it stays in sync with the pyramid above).

The time column stretches computer time so that 1 register access = 1 second. Same ratios, human-sized numbers. The brain doesn't really work in neat layers, but the trade-off is the same: what's closest to your attention is fastest, and what holds the most takes longest to reach.

Volatile vs. non-volatile: registers, cache (SRAM) and DRAM lose their contents when power is cut. SSDs (flash) and hard drives keep data. That's why programs are loaded from storage into RAM to run. In brain terms: switching off is like a deep sleep that wipes short-term memory, while long-term memory survives.

03 · Double data rate

DDR = data on both clock edges

Older SDRAM moved one chunk of data per clock cycle, on the rising edge. DDR (Double Data Rate) moves data on the rising and falling edge, so it transfers twice per cycle at the same clock frequency. That's why DDR speeds are quoted in MT/s (mega-transfers per second): DDR4-3200 runs its I/O clock at 1600 MHz but transfers 3200 million times per second.

Prefetch is the other trick. The DRAM core itself is slow (a few hundred MHz). Each internal access grabs several bits per data pin at once (the “prefetch”: 2n for DDR1, 8n for DDR3/4, 16n for DDR5) and the I/O then streams them out quickly. That's how the external transfer rate keeps climbing while the cells don't get much faster.

05 · Lanes & widths

Data lanes (DQ) and what “x4 / x8 / x16” means

Each DRAM chip has a number of data pins, called DQ lines. Think of each one as a lane carrying one bit per transfer. The chip's width is how many lanes it has:

  • x4: 4 data lanes (common on server RDIMMs: more chips = more capacity and better ECC coverage)
  • x8: 8 data lanes (the typical desktop DIMM chip)
  • x16: 16 data lanes (laptops, embedded boards, SoCs, graphics: fewer chips for a given bus width)

The memory controller has a fixed bus width (classic PC channel: 64 bits; plus 8 more for ECC = 72). Chips are placed side by side, each covering a slice of the bus, until the full width is filled. That group of chips that answers together is a rank.

“Lanes” vs. PCIe lanes: in PCIe, “x16” means 16 serial lanes, each a full-duplex differential pair. In DRAM, “x16” means a chip with 16 parallel data pins on a shared, half-duplex bus. Same notation, different technology.
06 · Configuration builder

“2×16” and “4×16”: chips × width

On board schematics, SoC datasheets and FPGA designs, a notation like 2×16 means two x16 DRAM chips wired side by side. Their lanes add up: 2 × 16 = a 32-bit bus. 4×16 is four x16 chips, making a 64-bit bus. More chips in parallel means more bandwidth and more capacity. Build one:

07 · Retail kits

The other “2×16”: a 2 × 16 GB kit

When you shop for RAM, 2×16GB means something different: two memory sticks of 16 GB each (32 GB total). 4×16GB is four sticks, 64 GB. What matters here is channels: most desktop CPUs have two memory channels, and each channel is its own 64-bit path. One stick per channel = dual-channel = double the bandwidth of a single stick.

Under the hood, the two meanings meet. A single-rank 16 GB DDR4 stick is often built as 8 chips × 16 Gb, each x8 (an “8×8” rank). A 16 GB DDR5 stick has two independent 32-bit sub-channels per stick, each filled by x8 or x16 chips. So a “2×16GB” kit is made of many small chip arrangements like the ones in section 6.
08 · Phone vs laptop vs desktop

Mobile memory (LPDDR) vs PC memory (DDR)

Phones and many thin laptops use LPDDR (Low-Power DDR), while desktops and many laptops use standard DDR on removable sticks. Both store bits the same way, but LPDDR is built to save battery: lower voltages, narrow 16-bit channels that can sleep independently, and extra low-power modes.
